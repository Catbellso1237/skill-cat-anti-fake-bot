# Agent notes

- Sửa bot ở https://github.com/Catbellso1237/cat-anti-fake-bot
- Đọc `SKILL.md` trước. Chi tiết nằm trong `references/`.

- Chỉ cập nhật skill khi hành vi bot đổi, và ghi commit mới lên đầu `SKILL.md`.
